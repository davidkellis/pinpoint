https://leafletjs.com
https://github.com/Leaflet/Leaflet/tree/v1.9.4

leaflet.js and leaflet.css are unmodified distribution assets downloaded from:
https://unpkg.com/leaflet@1.9.4/dist/leaflet.js
https://unpkg.com/leaflet@1.9.4/dist/leaflet.css

The full license is in LEAFLET-LICENSE and is embedded in generated map reports.
Leaflet image assets are not used: controls use text and markers use canvas.

The map uses Esri World Imagery tiles on demand, with visible attribution.
No basemap images are bundled, prefetched or downloaded by the CLI.
The plain-background mode uses no network resources.
